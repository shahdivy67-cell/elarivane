# Alivane — Meaningful Real-World Presence

Alivane is a mobile-first web app that helps people replace unintentional reels scrolling with enjoyable things to do, make, learn, and share with friends.

It is designed as an alternative you want to open — finite, purposeful, and easy to leave — avoiding screen-time tracker shaming and streak pressure.

## Key Features
- **3 Core Paths:**
  1. **Go Do**: Real-world missions (Move, Explore, Make, Connect, Reset) with photo logs and step guides.
  2. **Play & Unwind**: Self-contained creative pauses (3-color landscape canvas, Zen garden sand rake, 432Hz pentatonic chimes).
  3. **Curiosity**: Bite-sized visual explainers & mini-puzzles (The Moon Horizon Illusion, Wood Wide Web fungal routing, Kintsugi philosophy).
- **Dark-Green GitHub-style Heatmap**: Shows days with meaningful completed activities, with filters and data explanations.
- **Gentle Fellowship**: Friend invites, contact permission clarity, invite link generation, group circles, and reporting/blocking safety.
- **Offline First**: Offline indicator, local logging, and deduplicated background sync when reconnected.
- **Data Sovereignty**: Complete JSON data export and account reset options.
